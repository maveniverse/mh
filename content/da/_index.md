{{% blocks/lead color="primary" %}}
Maven-håndbogen er en bog skrevet af fællesskabet til alle, der bruger Apache Maven.

Fra den første `mvn verify` til indstillinger, POM, build-livscyklussen og bedste praksis:
vi forklarer, hvordan Maven virkelig fungerer, så dine builds holder op med at være magi og bliver kedelige (på den gode måde).
{{% /blocks/lead %}}


{{% blocks/section color="dark" type="row" %}}
{{% blocks/feature icon="fa-book-open" title="Lær Maven på den rigtige måde!" %}}
Start med det grundlæggende og arbejd dig op. Bogen følger den vej, et build
tager: fælles begreber, indstillinger og miljø, Project Object Model og
build-livscyklussen, og slutter med det store billede.
{{% /blocks/feature %}}


{{% blocks/feature icon="fa-lightbulb" title="Forstå, ikke bare kopier!" %}}
Kodestumper fra nettet virker, indtil de ikke gør. Her lærer du, *hvorfor* Maven
opfører sig, som den gør, så du kan ræsonnere om dine egne builds og rette dem
med selvtillid.
{{% /blocks/feature %}}


{{% blocks/feature icon="fa-check-circle" title="Anvend bedste praksis!" %}}
Hold dine builds hurtige, reproducerbare og nemme at vedligeholde. Lær de
metoder, der sparer dig (og dine kolleger) for at fejlsøge builds kl. 3 om natten.
{{% /blocks/feature %}}
