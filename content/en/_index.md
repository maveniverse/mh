{{% blocks/lead color="primary" %}}
The Maven Handbook is a community-written book for everyone using Apache Maven.

From the first `mvn verify` to settings, the POM, the build lifecycle and best practices:
we explain how Maven really works, so your builds stop being magic and start being boring (in a good way).
{{% /blocks/lead %}}


{{% blocks/section color="dark" type="row" %}}
{{% blocks/feature icon="fa-book-open" title="Learn Maven the right way!" %}}
Start with the basics and work your way up. The book follows the path a build
takes: common concepts, settings and environment, the Project Object Model and
the build lifecycle, finishing with the grand picture.
{{% /blocks/feature %}}


{{% blocks/feature icon="fa-lightbulb" title="Understand, not just copy-paste!" %}}
Snippets found online work until they don't. Here you learn *why* Maven
behaves the way it does, so you can reason about your own builds and fix them
with confidence.
{{% /blocks/feature %}}


{{% blocks/feature icon="fa-check-circle" title="Apply best practices!" %}}
Keep your builds fast, reproducible and easy to maintain. Learn the practices
that save you (and your colleagues) from debugging builds at 3am.
{{% /blocks/feature %}}
